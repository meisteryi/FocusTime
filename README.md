# 🎯 FocusTime (포커스타임)

카카오톡, 크롬 등 외부 알림과 시각적 방해 요소를 원천 차단하고, 온전히 몰입할 수 있도록 돕는 **작업 표시줄 은폐형 전체화면 포커스 애플리케이션**입니다.

---

## ✨ 핵심 기능

1. **작업 표시줄을 덮는 완전 전체화면 (True Fullscreen & Kiosk)**
   - 윈도우 작업 표시줄(Taskbar)까지 완전히 덮어 외부 앱의 알림 뱃지나 열린 창들을 시야에서 완벽히 배제합니다.
2. **살아 숨쉬는 딥 포레스트~청록 앰비언트 그라데이션 (Breathing Background)**
   - 눈의 피로를 최소화하는 깊은 녹색/청록색 톤의 광원이 5초 주기로 들숨/날숨처럼 부드럽게 호흡하며 심리적 긴장 완화와 알파파 몰입 상태를 유도합니다.
3. **앱 내 유튜브 즉시 검색 & 연관곡 무한 자동재생 (In-App Search & Endless Autoplay)**
   - 밖으로 나갈 필요 없이 앱 내에서 `[ 🔍 음악 검색 ]`을 눌러 원하는 키워드(예: "지브리 피아노", "로파이 코딩")를 치면 상위 결과가 즉시 뜹니다.
   - 곡을 선택하면 **광고 없이 즉시 재생**되며, **곡이 끝나면 다음 연관 곡이 끊김 없이 자동으로 이어서 무한 재생**됩니다.
   - `[◀◀]` 이전 곡, `[▶▶]` 다음 곡 넘기기 지원.
4. **실시간 시계 & 집중 시간 스톱워치**
   - 현재 시각과 오늘 요일/날짜를 대화면으로 시원하게 표시합니다.
   - 앱 실행과 동시에 누적 집중 시간이 초 단위로 정밀하게 기록되며, 일시정지 및 리셋이 가능합니다.
5. **이탈 방지 경고 시스템 (Exit Guard)**
   - 무의식적으로 `ESC`, `Alt+F4`, 우측 상단 닫기를 누를 때 화면 전체가 딤 처리되며 "현재 OO분째 몰입 중입니다. 정말 집중을 중단하시겠습니까?" 경고 팝업이 뜹니다.
6. **잠시 외출 (최소화) 기능**
   - 꼭 바탕화면이나 다른 창을 잠깐 확인해야 할 때를 위해 상단 `[ 🗕 잠시 외출 ]` 버튼 또는 단축키 `F10`을 누르면 안전하게 창을 최소화할 수 있습니다.

## 🚀 실행 방법

### 방법 1: 배치 파일 더블 클릭
* 탐색기에서 `run.bat` 파일을 더블 클릭하여 즉시 실행

### 방법 2: 터미널에서 실행
```powershell
python main.py
```

## ⌨️ 조작 단축키 및 컨트롤

* `[ 🔍 음악 검색 ]` : 앱 내에서 유튜브 음악 검색 및 대기열 등록
* `[ 📋 복사 ] / [ 📋 선택한 URL 복사 ]` : 검색 결과 창에서 각 곡의 YouTube 링크를 원클릭으로 클립보드에 복사
* `[ 📋 링크 복사 ]` : 하단 바에서 현재 재생 중인 음악의 YouTube 링크를 즉시 클립보드에 복사
* `📻 연관곡 자동재생: ON/OFF` : 곡 종료 시 다음 연관 곡으로 자동 전환 여부 토글
* `◀◀ / ▶▶` : 이전 곡 / 다음 곡 넘기기
* `F10` : 잠시 외출 (안전하게 앱 최소화)
* `ESC` : 이탈 방지 경고창 호출 (집중 계속하기 / 앱 종료 선택)
* `❚❚ 일시정지 / ▶ 재개` : 중앙 집중 타이머 일시 멈춤 및 재개
* `■ 리셋` : 타이머 0초로 초기화
